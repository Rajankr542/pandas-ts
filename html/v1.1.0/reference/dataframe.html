DataFrame

Two-dimensional, size-mutable, potentially heterogeneous tabular data. Contains labeled axes (rows and columns).

new DataFrame

#
new DataFrame(data, options?)

Construct a DataFrame from an object of arrays, an array of objects, another DataFrame, or a 2D array.

Parameters

dataRecord<string, unknown[]> | object[] | DataFrame | unknown[][]
The data.
options?{ index?, columns? }
Construction options.

Returns

DataFrame

Example

TypeScript
import { DataFrame } from 'pandas-ts';
const df = new DataFrame({ a: [1, 2, 3], b: [4, 5, 6] });
df.shape;    // => [3, 2]

DataFrame#assign

#
df.assign(cols)

Assign new columns to a DataFrame. Returns a new DataFrame with all existing columns plus any new ones.

DataFrame

TypeScript

DataFrame#merge

#
df.merge(right, options?)

Merge DataFrame objects with a database-style join.

Parameters

rightDataFrame
Right DataFrame to merge.
options?{ on?, how?, left_on?, right_on? }
Merge options. how defaults to 'inner'.

Returns

DataFrame

Example

TypeScript
const left = new DataFrame({ id: [1,2], name: ['Alice','Bob'] });
const right = new DataFrame({ id: [1,2], score: [90, 85] });
left.merge(right, { on: 'id' }).col('score').to_list();    // => [90, 85]

DataFrame#pivot_table

#
df.pivot_table(options)

Create a spreadsheet-style pivot table as a DataFrame.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({
  city: ['A','A','B','B'],
  year: [2023,2024,2023,2024],
  sales: [100,120,200,180]
});
const pt = df.pivot_table({ index: 'city', columns: 'year', values: 'sales', aggfunc: 'sum' });
pt.shape;    // => [2, 2]

DataFrame#melt

#
df.melt(options?)

Unpivot a DataFrame from wide to long format.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ id: [1,2], jan: [100,200], feb: [110,210] });
const melted = df.melt({ id_vars: 'id', value_vars: ['jan','feb'], var_name: 'month', value_name: 'sales' });
melted.shape;    // => [4, 3]

DataFrame#evalExpr

#
df.evalExpr(expr)

Evaluate an expression against the DataFrame columns. Returns a Series with the result. (Note: named evalExpr because eval is reserved in JavaScript.)

Returns

Series

Example

TypeScript
const df = new DataFrame({ a: [1,2,3], b: [4,5,6] });
df.evalExpr('a + b').to_list();    // => [5, 7, 9]

DataFrame#dropna (axis=1)

#
df.dropna({ axis?, how?, thresh? })

Remove missing values. axis=1 drops columns (instead of rows) that contain NA values according to how/thresh.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ a: [1, null], b: [3, 4] });
df.dropna({ axis: 1 }).columns;    // => ['b']

DataFrame#concat (axis=1)

#
DataFrame.concat(dfs, { axis? })

Concatenate DataFrames. axis=1 stacks them side-by-side (column-wise). Duplicate column names are auto-suffixed with _1, _2, etc.

Returns

DataFrame

Example

TypeScript
const df1 = new DataFrame({ a: [1,2] });
const df2 = new DataFrame({ b: [3,4] });
DataFrame.concat([df1, df2], { axis: 1 }).columns;    // => ['a','b']

DataFrame#to_dict

#
df.to_dict(orient?)

Convert the DataFrame to a dictionary. orient controls the output shape: 'dict' (default), 'list', 'records', 'series', 'split', 'index'.

Returns

object

Example

TypeScript
const df = new DataFrame({ a: [1,2], b: [3,4] });
df.to_dict('records');    // => [{ a:1, b:3 }, { a:2, b:4 }]
df.to_dict('split');      // => { index:[0,1], columns:['a','b'], data:[[1,3],[2,4]] }

DataFrame#to_string

#
df.to_string({ index?, max_rows?, max_cols? })

Render the DataFrame to a tab-separated string suitable for console output. Truncates to max_rows / max_cols with ... indicators.

Returns

string

Example

TypeScript
const df = new DataFrame({ x: [1,2,3], y: [4,5,6] });
console.log(df.to_string({ max_rows: 10 }));

DataFrame#convert_dtypes

#
df.convert_dtypes()

Convert columns to the best possible dtype. String/object columns whose values are all numeric strings are promoted to float64.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ a: ['1','2','3'], b: ['x','y','z'] });
df.convert_dtypes().col('a').dtype.name;    // => 'float64'

DataFrame#corr_matrix (spearman)

#
df.corr_matrix(method?, min_periods?)

Compute pairwise correlation. Supports 'pearson' (default) and 'spearman' (rank-based). Returns a square DataFrame.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ a: [1,2,3,4], b: [4,3,2,1] });
df.corr_matrix('spearman').col('b').iloc(0);    // => -1
