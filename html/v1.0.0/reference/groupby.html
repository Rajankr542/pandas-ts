API reference

GroupBy

Groupby operations follow the split-apply-combine paradigm. Group a DataFrame or Series, apply an aggregation or transformation, and combine into a result.

NameSummary
DataFrameGroupBy#sumCompute sum of group values.
DataFrameGroupBy#meanCompute mean of groups.
DataFrameGroupBy#minCompute minimum of group values.
DataFrameGroupBy#maxCompute maximum of group values.
DataFrameGroupBy#countCompute count of group values.
DataFrameGroupBy#stdCompute standard deviation of groups.
DataFrameGroupBy#aggAggregate using one or more operations.
DataFrameGroupBy#transformCall func producing a like-indexed DataFrame.
DataFrameGroupBy#filterReturn a copy of a DataFrame excluding elements from groups that do not satisfy the boolea
SeriesGroupBy#sumCompute sum of groups for a Series.
SeriesGroupBy#meanCompute mean of groups for a Series.

DataFrameGroupBy#sum

#
gbdf.sum()

Compute sum of group values.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ g: ['a','b','a'], v: [1,2,3] });
df.groupby('g').sum().col('v').to_list();    // => [4, 2]

DataFrameGroupBy#agg

#
gbdf.agg(func)

Aggregate using one or more operations.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ g: ['a','b','a'], v: [1,2,3] });
df.groupby('g').agg({ v: ['sum', 'mean'] }).columns;    // => ['v_sum', 'v_mean']

DataFrameGroupBy#transform

#
gbdf.transform(fn)

Call func producing a like-indexed DataFrame.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ g: ['a','a','b'], v: [1,3,2] });
df.groupby('g').transform(s => s.sub(s.mean())).col('v').to_list();    // => [-1, 1, 0]

DataFrameGroupBy#filter

#
gbdf.filter(fn)

Return a copy of a DataFrame excluding elements from groups that do not satisfy the boolean criterion specified by func.

Returns

DataFrame

Example

TypeScript
const df = new DataFrame({ g: ['a','a','b'], v: [1,2,3] });
df.groupby('g').filter(grp => grp.col('v').sum() > 2).col('v').to_list();    // => [1, 2, 3]

SeriesGroupBy#sum

#
gbs.sum()

Compute sum of groups for a Series.

Returns

Series

Example

TypeScript
const s = new Series([1, 2, 3, 4], { index: ['a','b','a','b'] });
s.groupby(s.index).sum().to_list();    // => [4, 6]
