API reference

tseries.offsets

Date offset classes for arithmetic on dates. All offsets have apply(date), rollforward(date) and rollback(date) methods.

NameSummary
BusinessDayA business-day offset. Skips Saturday and Sunday.
MonthEndAn offset corresponding to the last business day of the month.
MonthBeginAn offset corresponding to the first calendar day of the month.
YearEndAn offset for the last day of the year.
YearBeginAn offset for the first day of the year.
QuarterEndDateOffset increments between Quarter end dates.
QuarterBeginDateOffset increments between Quarter start dates.
WeekA week offset.
DayA calendar day offset.
HourAn hour offset.
MinuteA minute offset.
SecondA second offset.
BusinessHourDateOffset subclass representing possibly n business hours. Default business hou

BusinessDay

#
new BusinessDay(n?)

A business-day offset. Skips Saturday and Sunday.

Parameters

nnumber
Number of business days. Default 1.

Returns

BusinessDay

Example

TypeScript
import { BusinessDay } from 'pandas-ts';
const bd = new BusinessDay(1);
bd.apply(new Date('2024-01-05')).toDateString();    // Friday -> Monday: 'Mon Jan 08 2024'

new MonthEnd(n?)

TypeScript

BusinessHour

#
new BusinessHour(n?, start?, end?)

DateOffset subclass representing possibly n business hours. Default business hours: 09:00–17:00.

Returns

BusinessHour

Example

TypeScript
import { BusinessHour } from 'pandas-ts';
// Advancing from end of business hours rolls to next morning
const bh = new BusinessHour(1);
bh.rollforward(new Date('2024-01-05T18:00:00')).getHours();    // => 9
