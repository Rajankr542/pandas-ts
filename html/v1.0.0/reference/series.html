Series

A one-dimensional labeled array capable of holding any data type. The axis labels are collectively referred to as the index.

new Series

#
new Series(data, options?)

Construct a Series. data can be an array, object, typed array, or another Series. options.index sets the index labels; options.name names the Series; options.dtype overrides dtype inference.

Parameters

dataunknown[] | TypedArray | Record<string, unknown>
The data for the Series.
options?{ index?, name?, dtype? }
Construction options.

Returns

Series

Example

TypeScript
import { Series } from 'pandas-ts';
const s = new Series([1, 2, 3, 4, 5], { name: 'numbers' });
s.mean();    // => 3
s.std();     // => 1.5811388300841898
