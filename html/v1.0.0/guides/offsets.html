Date offset classes for date arithmetic. All offsets have three methods:

  • apply(date) — move the date by n units
  • rollforward(date) — snap to the next valid date if not already on one
  • rollback(date) — snap to the previous valid date

Available offsets#

ClassAliasesDescription
BusinessDayBDayA business day (Mon–Fri)
MonthEndMELast calendar day of the month
MonthBeginMSFirst calendar day of the month
YearEndYELast day of the year
YearBeginYSFirst day of the year
QuarterEndQELast day of the quarter
QuarterBeginQSFirst day of the quarter
Week—A calendar week
Day—A calendar day
HourHOne hour
MinuteT, MinOne minute
SecondSOne second
MilliMillisecond, msOne millisecond
BusinessHourBHA business hour (09:00–17:00)

Examples#

TypeScript
import { BusinessDay, MonthEnd, YearEnd, Week } from 'pandas-ts';

// Advance by 1 business day (Friday → Monday)
new BusinessDay(1).apply(new Date('2024-01-05')).toDateString();
// => 'Mon Jan 08 2024'

// Last day of the current month from Jan 15
new MonthEnd(1).apply(new Date('2024-01-15')).toDateString();
// => 'Wed Jan 31 2024'

// Last day of the current month — leap year Feb
new MonthEnd(1).apply(new Date('2024-01-31')).toDateString();
// => 'Thu Feb 29 2024'

// Advance to Dec 31
new YearEnd(1).apply(new Date('2024-06-15')).toISOString().slice(0,10);
// => '2024-12-31'

// 2 weeks forward
new Week(2).apply(new Date('2024-01-01')).getDate();
// => 15

rollforward and rollback#

TypeScript
import { BusinessDay } from 'pandas-ts';
const bd = new BusinessDay();

// Saturday → next Monday
bd.rollforward(new Date('2024-01-06')).toDateString();
// => 'Mon Jan 08 2024'

// Sunday → previous Friday
bd.rollback(new Date('2024-01-07')).toDateString();
// => 'Fri Jan 05 2024'

Using with date_range#

TypeScript
import { date_range } from 'pandas-ts';

// Month-end dates for all of 2024
const dates = date_range('2024-01-31', { periods: 12, freq: 'ME' });
